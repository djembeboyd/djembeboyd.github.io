WorkspaceMCP Privacy Policy

Last updated: October 6, 2026

Who uses this app

WorkspaceMCP is used only by its owner, on the owner's own computer, with the owner's own Google accounts.

What Google user data is accessed

With the owner's consent, the app accesses Gmail, Google Calendar, Google Drive, Google Docs, Sheets, Slides, Forms, Tasks, Contacts, Chat and Apps Script data of the signed-in account.

How the data is used

The data is used only to carry out the owner's own requests, such as searching mail, reading documents or adding calendar events.

Storage

OAuth tokens are stored only on the owner's computer. Google user data is not stored on any server operated for this app.

Sharing

Google user data is not sold, and is not shared with or transferred to any third party, except as needed to show results to the owner through the owner's chosen AI assistant.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
